# v1.1.6 Follow-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.1.6 with all 6 release-gate workarounds carried over from v1.1.5 physically removed (CHANGELOG "Known non-blocking limits" section deleted), plus the user's `http-bridge/install-windows-autostart.ps1` WIP landed.

**Architecture:** Two phases on `rc-1.1.6-candidate`. **Phase 1** is the high-risk A1 refactor (rc-branch orchestrator + evidence verifier moves to v1.1.3 strict fragment shape) done sequentially, gated by ≥ 2 consecutive clean `release-candidate.yml` runs. **Phase 2** is 6 independent worktrees in parallel (B1 SQLite busy retry, C1 Node-native archive, D1 mcp-stdio-idle EOF sentinel, D2 lifecycle teardown profile, D3 multi-process-stress cleanup, E1 autostart .ps1), each merged in order D1 → C1 → B1 → D2 → D3 → E1 with the corresponding workaround reverted in the same commit. **Phase 3** is the v1.1.6 release gate (rc-gate + release.yml + tag + gh release + CHANGELOG v1.1.5 "Known non-blocking limits" deleted).

**Tech Stack:** Node 24, TypeScript 5.x, vitest, GitHub Actions (ubuntu-latest / macos-latest / windows-latest), Zod 3.x, sqlite3, PowerShell 5.1, Bun (build only, not runtime).

## Global Constraints

- **Branch hygiene**: v1.1.6 work happens on `rc-1.1.6-candidate` (Phase 1 + 3) and 6 worktree-local feature branches (Phase 2: `feat/v116-b1-sqlite-busy` / `feat/v116-c1-node-archive` / `feat/v116-d1-stdio-idle-sentinel` / `feat/v116-d2-lifecycle-teardown` / `feat/v116-d3-stress-cleanup` / `feat/v116-e1-http-bridge-autostart`). No direct commits to `main` for v1.1.6 code (docs are fine).
- **Same-commit workaround revert**: each Phase 2 worktree reverts the workaround it owns in the same commit that lands the fix. **No** separate cleanup commit at the end.
- **Zero new npm dependencies**: prefer Node 24 built-ins (`zlib`, `fs/promises`, `crypto`, `worker_threads`); a `tar` npm package is acceptable for C1 only if its byte-level output matches GNU `tar` and the project doesn't already pin a version that breaks.
- **PowerShell 5.1 CJK safety** (E1): double-quoted strings containing CJK (`0x4E00`–`0x9FFF`) AND a `$(...)` subexpression trigger the tokenizer `MissingArrayIndexExpression` / `ParserError`. E1's commit must grep for `$\(` inside double-quoted CJK strings and replace with ASCII (or hoist the interpolation to a variable + `+` concat).
- **Test discipline**: every fix-task lands a test that exercises the new behavior on the OS that motivated the workaround (Windows for B1 / C1 / D3, orchestrator for D1 / D2, Windows host for E1).
- **CHANGELOG discipline**: v1.1.5's "Known non-blocking limits" section is **deleted** on v1.1.6 ship (not annotated, not nulled). v1.1.6's own section uses the same `Added / Removed / Verified` format as v1.1.5.
- **Worktree concurrency**: Phase 2 worktree pushes are staggered 10–15 min apart. PR template declares `concurrency: v116-{branch}` to serialize pushes of the same branch (not different branches).

export class SQLiteBusyError extends Error {
  readonly attempts: number;
  readonly lastError: unknown;
  constructor(message: string, attempts: number, lastError: unknown) {
    super(message);
    this.name = "SQLiteBusyError";
    this.attempts = attempts;
    this.lastError = lastError;
  }
}

const isBusy = (e: unknown): boolean => {
  const code = (e as { code?: string })?.code;
  return code === "SQLITE_BUSY" || code === "SQLITE_LOCKED" || code === "SQLITE_BUSY_SNAPSHOT";
};

export async function withBusyRetry<T>(
  op: () => Promise<T>,
  opts: { maxRetries?: number; initialDelayMs?: number; maxDelayMs?: number; backoff?: number } = {}
): Promise<T> {
  const maxRetries = opts.maxRetries ?? 5;
  const initialDelayMs = opts.initialDelayMs ?? 10;
  const maxDelayMs = opts.maxDelayMs ?? 200;
  const backoff = opts.backoff ?? 2;
  let delay = initialDelayMs;
  let lastError: unknown;
  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      return await op();
    } catch (e) {
      lastError = e;
      if (!isBusy(e) || attempt === maxRetries) {
        if (isBusy(e)) {
          throw new SQLiteBusyError(
            `SQLite busy after ${attempt + 1} attempts`,
            attempt + 1,
            lastError
          );
        }
        throw e;
      }
      await new Promise((r) => setTimeout(r, delay));
      delay = Math.min(delay * backoff, maxDelayMs);
    }
  }
  // Unreachable, but TypeScript needs it
  throw new SQLiteBusyError("unreachable", maxRetries + 1, lastError);
}
```

import { createHash } from "node:crypto";
import { createGzip } from "node:zlib";
import { createReadStream, createWriteStream } from "node:fs";
import { readdir, stat } from "node:fs/promises";
import { join, relative, sep, posix } from "node:path";
import { pipeline } from "node:stream/promises";

const TAR_BLOCK = 512;
const ZERO = Buffer.alloc(TAR_BLOCK);

function tarHeader(name: string, size: number, mode = 0o644, mtime = Math.floor(Date.now() / 1000)): Buffer {
  const nameBuf = Buffer.alloc(100);
  Buffer.from(name.slice(0, 99)).copy(nameBuf);
  const modeBuf = Buffer.from(mode.toString(8).padStart(7, "0") + "\0");
  const uidBuf = Buffer.from("0000000\0");
  const gidBuf = Buffer.from("0000000\0");
  const sizeBuf = Buffer.from(size.toString(8).padStart(11, "0") + " ");
  const mtimeBuf = Buffer.from(mtime.toString(8).padStart(11, "0") + " ");
  const chksumBuf = Buffer.alloc(8);
  const typeflag = Buffer.from("0");
  const linkname = Buffer.alloc(100);
  const magic = Buffer.from("ustar\0", "ascii");
  const version = Buffer.from("00", "ascii");
  const uname = Buffer.from("root\0");
  const gname = Buffer.from("root\0");
  const devmajor = Buffer.alloc(8);
  const devminor = Buffer.alloc(8);
  const prefix = Buffer.alloc(155);
  const pad = Buffer.alloc(12);

  const header = Buffer.concat([
    nameBuf, modeBuf, uidBuf, gidBuf, sizeBuf, mtimeBuf, chksumBuf, typeflag, linkname, magic, version, uname, gname, devmajor, devminor, prefix, pad
  ]);
  // Compute checksum
  const chksum = Buffer.alloc(8);
  let sum = 0;
  for (const b of header) sum += b;
  chksum.write(sum.toString(8).padStart(6, "0") + "\0 ");
  sum = 0;
  for (let i = 0; i < header.length; i++) {
    if (i >= 148 && i < 156) continue; // checksum field itself
    sum += header[i];
  }
  chksum.write(sum.toString(8).padStart(6, "0") + "\0 ");
  return Buffer.concat([header.slice(0, 148), chksum, header.slice(156)]);
}

async function* walkTar(srcDir: string, baseDir: string): AsyncGenerator<{ header: Buffer; body: Buffer | null }> {
  const entries = await readdir(srcDir, { withFileTypes: true });
  for (const entry of entries) {
    const full = join(srcDir, entry.name);
    const rel = posix.join(relative(baseDir, full).split(sep).join("/"));
    if (entry.isDirectory()) {
      const dirHeader = tarHeader(rel + "/", 0, 0o755);
      yield { header: dirHeader, body: null };
      yield* walkTar(full, baseDir);
    } else if (entry.isFile()) {
      const s = await stat(full);
      yield { header: tarHeader(rel, s.size), body: null };
      const file = await import("node:fs/promises").then((m) => m.readFile(full));
      // Pad to TAR_BLOCK
      const padSize = (TAR_BLOCK - (file.length % TAR_BLOCK)) % TAR_BLOCK;
      const body = Buffer.concat([file, Buffer.alloc(padSize)]);
      // Yield body in TAR_BLOCK chunks
      for (let i = 0; i < body.length; i += TAR_BLOCK) {
        yield { header: body.slice(i, i + TAR_BLOCK), body: null };
      }
    }
  }
}

export async function archive(
  srcDir: string,
  destFile: string,
  format: "tar.gz" | "zip"
): Promise<{ sha256: string; size_bytes: number }> {
  if (format === "zip") {
    // Defer to existing platform-specific zip path
    if (process.platform === "win32") {
      const { execFile } = await import("node:child_process/promises");
      await execFile("powershell.exe", ["-NoProfile", "-Command", `Compress-Archive -Path '${srcDir}\\*' -DestinationPath '${destFile}' -Force`]);
    } else {
      const { execFile } = await import("node:child_process/promises");
      await execFile("zip", ["-r", destFile, "."], { cwd: srcDir });
    }
  } else {
    // tar.gz: stream tar into gzip
    const hash = createHash("sha256");
    const out = createWriteStream(destFile);
    const gz = createGzip();
    const tarChunks: Buffer[] = [];
    for await (const { header } of walkTar(srcDir, srcDir)) {
      tarChunks.push(header);
    }
    tarChunks.push(ZERO); // EOF: two zero blocks
    tarChunks.push(ZERO);
    const tarBuf = Buffer.concat(tarChunks);
    hash.update(tarBuf);
    gz.write(tarBuf);
    gz.end();
    await new Promise<void>((resolve, reject) => {
      out.on("finish", resolve);
      out.on("error", reject);
      gz.pipe(out);
    });
  }
  const { readFile } = await import("node:fs/promises");
  const buf = await readFile(destFile);
  return { sha256: createHash("sha256").update(buf).digest("hex"), size_bytes: buf.length };
}
```

(Implementation note: the `walkTar` above yields body chunks via the same channel as headers; the consumer treats both as `TAR_BLOCK` bytes. Real implementation may split into two channels. The important contracts: produces valid USTAR tar, streams through gzip, returns sha256 + size.)

async function cleanup(homes: string[], children: ChildProcess[]): Promise<void> {

  for (const child of children) {

  }

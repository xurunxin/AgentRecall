### 2.1 PR-M0-1 — `feat(idempotency-v2): transactional reservation + tool/actor namespace`

> 对应 issue #1（P0，concurrency）

**目标**：mutation 幂等在事务内、namespace 包含 tool、指纹递归 canonical、崩溃安全。

**改动点**：
- `src/sqlite-store.ts` schema v4 → v5：
  ```sql
  -- mutation_requests 重建：PK 从 (actor_id, key) → (actor_id, tool_name, key)
  -- 新增 state (pending | completed)、request_id、created_at、completed_at
  -- 保留 (actor_id, tool_name, key) 旧行 1 个 release 周期做兼容读
  CREATE TABLE mutation_requests_v2 (
    actor_id TEXT NOT NULL,
    tool_name TEXT NOT NULL,
    idempotency_key TEXT NOT NULL,
    state TEXT NOT NULL CHECK (state IN ('pending','completed')),
    request_hash TEXT NOT NULL,
    result_json TEXT,
    request_id TEXT,
    created_at INTEGER NOT NULL,
    completed_at INTEGER,
    PRIMARY KEY (actor_id, tool_name, idempotency_key)
  );
  -- DOWN 路径保留 mutation_requests 旧表 + 自动 migrate
  ```
- `src/services/idempotency.ts`：
  - 替换 `hashRequest` — 递归 canonical JSON serializer（按 key 排序 + 跳过 `undefined` + 数组保序 + NaN/Infinity 拒绝）
  - 新增 `reserveIdempotency(store, actor, tool, key, requestHash, requestId): {kind: "fresh" | "replay" | "rejected"}`，在 BEGIN IMMEDIATE 事务内调用
  - 新增 `completeIdempotency(store, actor, tool, key, result)`，写 `state=completed, result_json, completed_at`
  - 弃用 `lookupIdempotency`（保留 wrapper 1 个 release 周期）
- `src/services/memory-write-service.ts` — 所有 mutation（remember/update/supersede/merge/forget）在主事务内：
  1. `BEGIN IMMEDIATE`
  2. `reserveIdempotency(...)` — 命中 replay 直接 COMMIT + 返回
  3. 执行 mutation
  4. 写 revisions / audit
  5. `completeIdempotency(...)` 写 result
  6. `COMMIT`
- `src/portability/importer.ts` 的 import 路径**不**走 idempotency（批量导入有自己的事务）
- `src/cli/commands/import.ts` 也不走

**验收标准**：

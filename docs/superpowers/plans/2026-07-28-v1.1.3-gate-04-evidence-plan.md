`release-evidence.schema.json` exports a zod schema:

```ts
export const ReleaseEvidence = z.object({
  schema_version: z.literal("1.1.3"),
  version: z.string().regex(/^\d+\.\d+\.\d+$/),
  release_commit: z.string().regex(/^[0-9a-f]{40}$/),
  tag: z.string().regex(/^v\d+\.\d+\.\d+$/),
  candidate_sha: z.string().regex(/^[0-9a-f]{40}$/),
  subissues: z.array(z.object({ number: z.number(), state: z.literal("closed"), title: z.string() })),
  ci_jobs: z.array(z.object({
    platform: z.enum(["linux-x64", "darwin-x64", "win32-x64"]),
    os: z.string(),
    node: z.string(),
    job_url: z.string().url().refine(u => u.startsWith("https://github.com/") || u.startsWith("local://"), "github or local only"),
    conclusion: z.enum(["success", "failure"]),
    duration_ms: z.number().int().nonnegative(),
    head_sha: z.string().regex(/^[0-9a-f]{40}$/),
  })),
  release_workflow: z.object({ /* same shape as ci_jobs entry, x1 */ }),
  artifacts: z.array(z.object({
    platform: z.enum(["linux-x64", "darwin-x64", "win32-x64"]),
    name: z.string(),
    size_bytes: z.number().int().nonnegative(),
    sha256: z.string().regex(/^[0-9a-f]{64}$/),
  })),
  sha256_checksums: z.record(z.string(), z.string().regex(/^[0-9a-f]{64}$/)),
  test_summary: z.object({
    passed: z.number().int().nonnegative(),
    failed: z.number().int().nonnegative(),
    skipped: z.number().int().nonnegative(),
    filtered: z.number().int().nonnegative(),
    totals_from: z.enum(["actual", "constant"]),
  }),
  stress_summary: z.object({
    process_count: z.number().int().nonnegative(),
    operations: z.number().int().nonnegative(),
    invariants_ok: z.number().int().nonnegative(),
  }),
  migration_summary: z.object({
    sources_tested: z.array(z.string()),
    each_passed: z.boolean(),
  }),
  known_non_blocking_limits: z.array(z.string()),
});
```

### Commit 2 — Verifier

```text
scripts/verify-release-evidence.mjs (NEW)
```

Implementation:
- Loads the doc, walks every field, applies the stable reason
  codes per the design spec.
- Returns exit 0 on success; non-zero with reason on failure.
- Logs the reason to stderr (machine-parseable JSON).
- Stable mode (`--stable`) is the default; dev mode (`--dev`)
  tolerates `local://` URLs and `constant` test totals.

### Commit 3 — Aggregator

```text
scripts/release-evidence.mjs (MODIFIED)
```

Implementation:
- Reads `release-candidate.yml` matrix outputs (3 fragments
  on disk).
- Canonicalises each fragment's `platform` token to the
  canonical vocabulary.
- Merges into a single `release-evidence.json` document.
- `test_summary.totals_from` is read from the actual
  Vitest JSON fragment; the legacy fallback to constants
  is removed.

### Commit 4 — Negative fixtures

```text
test/release-gate/p3-release-evidence-negative.test.ts (NEW)
```

One fixture per stable reject reason:
- `LOCAL_URL_FORBIDDEN` — local:// in stable mode
- `PLATFORM_NOT_CANONICAL` — `windows-x64` artifact
- `CHECKSUM_TYPE_INVALID` — array as checksum
- `CHECKSUM_BYTES_MISMATCH` — sha256 of bytes != recorded
- `CANDIDATE_SHA_MISMATCH` — candidate != release
- `DURATION_PLACEHOLDER` — duration_ms == 0
- `TEST_TOTALS_FROM_CONSTANT` — totals_from == "constant"
- `MISSING_GITHUB_JOB_URL` — local:// in stable mode
- `EMPTY_ARTIFACTS` / `DUPLICATE_ARTIFACTS`
- `SCHEMA_INVALID` — missing field

### Commit 5 — Aggregator happy path

```text
test/release-gate/p3-release-evidence-aggregator.test.ts (NEW)
```

- Write 3 fragments (one per platform) to a tempdir.
- Call the aggregator.
- Call the verifier on the result.
- Assert exit 0.

Plus negative case:
- Drop one fragment → exit non-zero with reason.
- Modify one fragment's sha256 → exit non-zero with
  `CHECKSUM_BYTES_MISMATCH`.

### Commit 6 — prepare-release fail-closed

```text
scripts/prepare-release.mjs (MODIFIED)
```

Implementation:

  (caller must choose).

  document.

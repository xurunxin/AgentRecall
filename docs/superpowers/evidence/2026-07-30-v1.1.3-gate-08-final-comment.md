### Lane-local deviation (recorded in 2026-07-30-v1.1.3-gate-08-tag.md)

scripts/prepare-release.mjs shells git tag -a v1.1.3 -F <msg> --author=<author> which is rejected by every standard Git (git tag has no --author option; verified with git tag --help on Git 2.55.0). The lane creates the tag with the canonical temp-author-env mechanism the design spec describes (git -c user.name=... -c user.email=... tag -a v1.1.3 366bc98 -F <msg>) so ~/.gitconfig is NOT mutated. The fix to prepare-release.mjs is a separate follow-up; the lane is gated on no source changes.
